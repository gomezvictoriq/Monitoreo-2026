1 Relevamiento de estaciones hidrológicas

En Argentina, el monitoreo y estudio de los recursos hídricos está a cargo de organismos nacionales y provinciales, destacándose el Instituto Nacional del Agua (INA) y la Subsecretaría de Recursos Hídricos.

En Argentina hay varias redes de monitoreo.

La red principal de monitoreo es la Red Hidrológica Nacional (RHN) es la mayor fuente de información: hidrológica (altura y caudal de los ríos); meteorológica (lluvia, evaporación, temperatura, humedad, presión atmosférica, velocidad/dirección del viento, radiación solar); nivológica (equivalente de agua en nieve); y de calidad de agua del país.

Algunas redes que están adheridas a la RHN son:

• Red SiNaRaME (Sistema Nacional de Radares Meteorológicos)

• Red Hidrológica COREBE (Comisión Regional del Río Bermejo)

• Red Hidrológica CIRHBAS (Comité Interjurisdiccional de la Región Hídrica de los Bajos Submeridionales)

• Red Meteorológica RMET

• Red Hidrológica CIRHNOP

La Subsecretaria de Recursos Hídricos, organismo encargado de gestionar la infraestructura de medición y la base de batos hidrológica integrada.

Base de datos consultadas

1.1 Sistema Nacional de Información Hídrica (SNIH)

El Sistema Nacional de Información Hídrica (SNIH), tiene el objetivo de recolectar, procesar y almacenar los datos básicos obtenidos de la Red Hidrológica Nacional y de otras redes adheridas para ser utilizados por los organismos nacionales, provinciales e interjurisdiccionales relacionados con los recursos hídricos y el medio ambiente.

Sitio web SNIH

1.2 Instito Nacional del Agua (INA)

El SIyAH (Sistema de Información y Alerta Hidrológico) que monitorea en tiempo real el comportamiento de los ríos, especialmente en la Cuenca del Plata. Operado por el Instituto Nacional del Agua (INA), es un servicio técnico y científico encargado de monitorear, diagnosticar y pronosticar el comportamiento de los ríos Paraná, Paraguay, Uruguay e Iguazú. max_idx = df['altura'].idxmax()

fig.add_annotation(
    x=df.loc[min_idx, 'Fecha y Hora'],
    y=df.loc[min_idx, 'altura'],

    arrowhead=2,
    arrowsize=1,
    arrowwidth=2,
    arrowcolor='red'
)

fig.add_annotation(
    x=df.loc[max_idx, 'Fecha y Hora'],
    y=df.loc[max_idx, 'altura'],
    text=f"Máximo: {df.loc[max_idx, 'altura']}m",
    showarrow=True,
    arrowhead=2,
    arrowsize=1,
    arrowwidth=2,
    arrowcolor='green'
)

# Guardar la gráfica como un archivo HTML con dimensiones correctas
fig.write_html(
    "grafica.html",
    include_plotlyjs='cdn',
    full_html=True,
    default_width='100%',

import pandas as pd

df_alturas = pd.read_csv(r"D:\Monitoreo 2026\Output\csv\Corrientes\Alturas")
df_ph = pd.read_csv(r"Output/csv/Corrientes/pH")

# 1. Asegurarse de que las columnas de fecha sean datetime (ya lo están según tu output)
# Pero por seguridad, forzamos el formato si hubiera dudas
df_ph['Fecha y Hora'] = pd.to_datetime(df_ph['Fecha y Hora'])
df_alturas['Fecha y Hora'] = pd.to_datetime(df_alturas['Fecha y Hora'])

# 2. IMPORTANTE: Ordenar ambos DataFrames por la columna de fecha
# merge_asof REQUERIR que los datos estén ordenados cronológicamente
df_ph = df_ph.sort_values('Fecha y Hora')
df_alturas = df_alturas.sort_values('Fecha y Hora')

# 3. Realizar la fusión con merge_asof
df_fusionado = pd.merge_asof(
    df_ph,       # Tabla principal (la que tiene muchas filas)
    df_alturas,             # Tabla de referencia (la que tiene 1 altura por día)
    on='Fecha y Hora',      # Columna de tiempo común
    direction='backward'    # 'backward': Toma la altura más reciente ANTES de la hora de la medición química.
                            # Esto es ideal: Si midiste pH a las 12:00, toma la altura de las 07:00.
)

# 4. Limpiar nombres de columnas si es necesario
# Ahora tendrás: Fecha y Hora, Conductividad, altura, día (de la tabla de alturas)
print(df_fusionado)

# Correlación

# Asegúrate de que las columnas sean numéricas (a veces vienen como texto por errores de lectura)
# Tu DataFrame se llama df_fusionado (o el nombre que le diste)
df_fusionado['pH [UpH]'] = pd.to_numeric(df_fusionado['pH [UpH]'], errors='coerce')
df_fusionado['altura'] = pd.to_numeric(df_fusionado['altura'], errors='coerce')

# Eliminar filas donde falten datos en cualquiera de las dos columnas
# (La correlación no se puede calcular con valores NaN)
df_limpio = df_fusionado.dropna(subset=['pH [UpH]', 'altura'])

# Calcular la correlación
r = df_limpio['pH [UpH]'].corr(df_limpio['altura'])

print(f"Coeficiente de correlación (r): {r:.4f}")

import pandas as pd
import matplotlib.pyplot as plt
import numpy as np

# ==========================================
# 1. PREPARACIÓN DE DATOS
# ==========================================
# Asumiendo que tu dataframe fusionado se llama 'df_fusionado'
# Si lo guardaste en una variable diferente, cambia el nombre aquí.

# 1.1 Aseguramos que sean numéricas
col_ph = 'pH [UpH]'  # Ajusta este nombre si tu columna se llama diferente
col_alt = 'altura'           # Ajusta este nombre si tu columna se llama diferente

# Verificar si las columnas existen (para evitar errores)
if col_ph not in df_fusionado.columns or col_alt not in df_fusionado.columns:
    print("❌ Error: No se encontraron las columnas 'pH [UpH]' o 'altura'.")
    print(f"Columnas disponibles: {df_fusionado.columns.tolist()}")
else:
    # Convertir a numérico (descartando textos o errores)
    df_fusionado[col_ph] = pd.to_numeric(df_fusionado[col_ph], errors='coerce')
    df_fusionado[col_alt] = pd.to_numeric(df_fusionado[col_alt], errors='coerce')

    # Eliminar filas con NaN (datos faltantes) para el cálculo y gráfico
    df_limpio = df_fusionado.dropna(subset=[col_ph, col_alt])



    # ==========================================
    # 2. CÁLCULO DE CORRELACIÓN
    # ==========================================
    if len(df_limpio) > 0:
        r = df_limpio[col_ph].corr(df_limpio[col_alt])
        print(f"\n📊 Coeficiente de Correlación (r): {r:.4f}")
    else:
        r = 0
        print("\n⚠️ No hay datos suficientes para calcular la correlación.")

    # ==========================================
    # 3. GENERAR GRÁFICO
    # ==========================================
    plt.style.use('seaborn-v0_8-whitegrid') # Estilo limpio
    fig, ax = plt.subplots(figsize=(10, 6))

    # Crear el scatter plot
    # s=40: tamaño de los puntos
    # alpha=0.6: transparencia para ver superposiciones
    scatter = ax.scatter(df_limpio[col_alt], df_limpio[col_ph], 
                         color='#1f77b4', alpha=0.6, edgecolors='w', s=50, label='Datos Medidos')

    # Opcional: Añadir una línea de tendencia (Regresión lineal)
    if len(df_limpio) > 1:
        # Calcular pendiente e intersección
        m, b = np.polyfit(df_limpio[col_alt], df_limpio[col_ph], 1)
        # Dibujar la línea
        x_line = np.linspace(df_limpio[col_alt].min(), df_limpio[col_alt].max(), 100)
        ax.plot(x_line, m * x_line + b, color='#d62728', linewidth=2, label=f'Tendencia (r={r:.2f})')

    # Configuración de etiquetas y título
    ax.set_xlabel(f'Altura del Río ({col_alt})', fontsize=12)
    ax.set_ylabel(f'pH', fontsize=12)
    ax.set_title(f'Relación: pH vs. Altura\n(Coeficiente de Pearson r = {r:.3f})', fontsize=14, fontweight='bold')
    ax.legend()

    # Limitar ejes si hay valores extremos (outliers) que rompen la escala
    # Esto ayuda a ver mejor la mayoría de los puntos
    # ax.set_xlim(left=0) # Si la altura no puede ser negativa
    # ax.set_ylim(bottom=0) # Si la turbidez no puede ser negativa

    plt.tight_layout()
    plt.show()

📊 Coeficiente de Correlación (r): -0.4285
